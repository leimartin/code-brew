# Code Brew

## About the Project
Code Brew is an Android food delivery application that offers a fun and user-friendly experience through its programming-inspired menu. Users can create accounts, browse food and drinks, add items to their cart, review orders, and calculate the total cost, including taxes and delivery fees. The app supports various payment methods and includes settings for account information and an information page about the app and its developers. Designed for programmers, coffee lovers, and food enthusiasts, Code Brew aims to make food ordering convenient and enjoyable. In the future, it may expand its menu, introduce new features, and partner with local restaurants and cafés to reach more customers.

## Application Features
| Feature | Description |
|---|---|
| Sign In/Sign Up | Allows users to register and log in to their accounts. |
| Introduction Screen | Displays the app logo and a Begin button. |
| Main Menu | Browse pastries, beverages, and product categories. |
| Add to Cart | Add, remove, and adjust item quantities. |
| Checkout Screen | Review orders and proceed to checkout. |
| Payment Method | Demonstrates the selection of a preferred payment method. |
| Settings Screen | Provides access to profile and app information. |
| Profile Screen | Displays the user's registered information. |
| Info Screen | Shows application details and the development team. |
